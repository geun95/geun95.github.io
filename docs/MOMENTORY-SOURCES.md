# Momentory 콘텐츠 근거

사용자가 제공한 50쪽짜리 팀 최종보고서를 참고해 웹사이트의 소개·문제·해결·기능·결과를 갱신했습니다. 아래 쪽수는 PDF의 실제 페이지 번호입니다. 원본 보고서 전체를 사이트에 게시하지 않습니다.

## 사용자 확인과 보고서의 구분

- 표시 이름 Jung Jieun, 제출자 이름 정지은, 개발 기간 2026.06 ~ 현재, 3인 팀, 본인의 AI·Backend 역할, 공개 이메일은 사용자의 직접 확인을 따릅니다.
- Momentory에서 직접 사용한 기술은 사용자가 확인한 Java, Spring Boot, Gemini API, Jev, PostgreSQL, Docker, Git/GitHub입니다. 숙련도 점수는 부여하지 않았습니다.
- 이후 사용자가 별도로 제공한 Skills 참고 이미지에 맞춰 메인 개인 기술 목록은 15개로 갱신했습니다. 이 목록 전체를 Momentory에서 사용했다고 표현하지 않습니다.
- 보고서 21쪽의 정지은 역할 표기는 AI·데이터입니다. 표의 회고 질문·프롬프트 설계, 감정·주제 분석과 안전 필터링, 분석 리포트 로직은 기여 설명에 반영했습니다. 역할 제목은 사용자가 직접 확인한 AI·Backend로 유지합니다.
- 개인화 A/B 테스트 설계·분석과 앱 화면 구현은 사용자가 별도로 확인한 업무입니다. 프론트엔드 전체를 개인 단독 성과로 표현하지 않았습니다.

## 보고서 내부의 차이와 제외한 항목

- 7일 내 다음 AI 회고 완료 값은 2·5·42·45·47·50쪽에서 22/49명(44.9%), 43쪽 본문에서 21/49명(42.9%)으로 제시됩니다. 원시 집계 재확인 전에는 재회고율 수치를 사이트에 싣지 않았습니다.
- 보고서의 핵심 지표인 ‘가입 2주 이상 사용자 중 최근 7일 3일 이상 회고 완료 비율’과 ‘첫 AI 회고 후 7일 내 다음 회고 완료’는 정의가 다릅니다. 둘을 같은 지표로 쓰지 않습니다.
- 바람카드·리프레이밍을 중심으로 한 초기 소개는 현재 기능 흐름으로 갱신했습니다. 8~9쪽과 47쪽의 기획 전환·행동 선택 단계 축소를 근거로 합니다.
- 개인화·다음 날 편지의 재방문 개선 효과나 유료화 성과를 확정된 결과로 쓰지 않았습니다. 보고서에 있는 가격·매출 가설과 논문 투고 계획도 완료된 성과로 쓰지 않았습니다.
- 보고서의 테스트 계정과 로그인 정보는 추출·게시 대상에서 제외했습니다. 원본 PDF나 텍스트 추출본을 저장소에 올리지 않았습니다.
