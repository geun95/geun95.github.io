# 제출 파일

실제 GitHub Pages 배포를 확인한 다음 아래 명령으로 URL 한 줄만 담긴 파일을 생성합니다.

```sh
python3 scripts/create-submission.py --name 'Jung Jieun' --url https://geun95.github.io/
```

출력: `submission/Jung Jieun-공작과제-06.txt`

2026-11-22 실제 배포 URL을 확인하고 `Jung Jieun-공작과제-06.txt`를 생성했습니다. 내용은 `https://geun95.github.io/` 한 줄입니다. 배포 전 예시 URL로 제출 파일을 만들지 않도록 생성 스크립트가 응답과 포트폴리오 내용을 확인합니다.
